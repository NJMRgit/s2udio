## Context

User request (2026-08-12): investigate and, if possible, **name the
cava node used by s2udio**. Investigation: cava's PipeWire input
hardcodes the stream name (`pw_stream_new_simple(loop, "cava", ...)` in
`input/pipewire.c`), so every cava instance publishes `node.name =
media.name = "cava"`; there is no cava config/env option, and
WirePlumber cannot rename an app-set `node.name` from outside (the
0.4-style `nickname` metadata rename is not implemented in WirePlumber
0.5). A tiny LD_PRELOAD shim that injects `node.name`/`media.name` from
an env var into the stream props was proven live.

## Change (host-implemented, round-29 commit)

1. **`cava.ron` / config `node_name` option**: `CavaInput.node_name`
   (`Option<String>`; `None` = cava's own name, `Some("")` = explicit
   disable). Main config (`cava.input.node_name`) and the sidecar
   (`CavaOverridesFile.node_name`) both support it; the settings panel
   preserves it across Save without editing it.
2. **LD_PRELOAD shim** `scripts/cava-node-name.c` (new), built by
   `setup.sh` into `~/.local/share/s2udio/libcavaname.so`
   (`S2UDIO_CAVA_NAME_SHIM` overrides the path). Intercepts
   `pw_stream_new_simple` and sets `node.name`/`media.name` from
   `CAVA_NODE_NAME`; a transparent pass-through when the env is unset.
3. **`CavaPane::spawn_cava`**: when `node_name` is configured, spawns
   `cava` with `LD_PRELOAD=<shim> CAVA_NODE_NAME=<name>` (missing shim =
   warn + fall back to cava's own name). Only the s2udio-spawned cava
   carries the env.
4. `shared::paths::cava_node_name_shim()` — shim lookup helper.
   Example config + docs updated.

Tests: +3 (`node_name_override_sets_and_disables`,
`main_config_input_parses_node_name`,
`node_name_rename_env_filters_empty_names`). **1364/1364**, warnings 3

## Acceptance criteria (host-validated after the pull)

- With `node_name: Some("s2udio-cava")` in `~/.config/s2udio/cava.ron`,
  `pw-dump`/`pw-cli ls Node` show the s2udio-spawned cava stream as
  **`s2udio-cava`** (node.name AND media.name); other cava instances
  keep "cava".
- Unset/empty `node_name` → cava runs unrenamed ("cava").
- A Settings → cava Save does not drop the hand-set `node_name`.
- `cargo test --release` green; binary warnings ≤ 3 baseline.
