## Context

User request (2026-08-12), multi-select UX round. Three changes:

1. **Ctrl+A selects all items in the current pane** — applies to
   **Queue / Playlists / MPD**; does NOT apply to **Jellyfin / Radio /
   Help / Settings / the MPD search filter pane** (search *results* pane
   is a gray area — the user lists "MPD search filter pane" as excluded,
   i.e. the filters column; results are covered by the general
   queue/library/search-results bulk-action wording, so results likely
   select-all too — isodev to confirm the boundary and pick sensibly).
2. **Ctrl+Click must ADD to the existing selection** (additive), not
   replace it — currently ctrl+clicking a second item deselects the
   initially selected item. The first click should leave a marked set and
   every subsequent ctrl+click grows it.
3. **Multi-selection gains bulk actions** (queue / library / search
   results):
   - "add tracks to queue"
   - "remove tracks from playlist"
   - "add tracks to playlist"
   - Add/create playlist must add **only the selected tracks** to the
     playlist.
   - Two NEW options: **"Add queue to playlist"** and **"Create playlist
     from queue"** — i.e. the whole queue (or its selection?) as a
     playlist-source.

## Decisions (isodev, host-implemented 2026-08-12)

- **Ctrl+A applies to the search *results* pane** (it is a list like the
  queue/library); the excluded "MPD search filter pane" is the left
  filter column (a no-op in the Search phase).
- **"Current pane" per tab**: Queue = the active Audio/Video list
  (Chapters untouched — it has no multi-select); Playlists = the songs
  pane only (at the root the playlists list is a no-op); MPD = the right
  Library pane (the folder tree is excluded).
- **Bulk actions reuse the existing context menu** (Enter/right-click);
  the menu acts on the marked set when any rows are marked, else the
  highlighted row.
- **"Add queue to playlist" / "Create playlist from queue" are
  whole-queue** (the pre-existing options; *Create audio playlist* was
  renamed *Create playlist from queue*). Marked rows additionally get
  *Add selected to playlist* / *Create playlist from selected* (only the
  selected tracks land in the playlist).
- **Ctrl+click is purely additive**: the row under the cursor joins the
  marks too (the initially selected item is never dropped) and clicking
  an already-marked row keeps it (no toggle-off). Plain click on another
  row / Esc still clear everything.

## Acceptance criteria (host validates after the pull)

- Ctrl+A in Queue/Playlists/MPD marks every item in the focused list
  pane; a second Ctrl+A keeps them marked (toggle-off only via Esc);
  no-op in Jellyfin/Radio/Help/Settings and in the MPD search filter
  column.
- Ctrl+Click on a second/third row adds it to the already-marked set
  (first click marks, later clicks accumulate) — no deselect of the
  earlier marks. Plain click still resets to a single selection.
- With multiple rows marked in queue/library/search results, the context
  menu (Enter / right-click) offers the bulk actions: add tracks to
  queue, remove tracks from playlist (playlists songs pane), add tracks
  to playlist (target picker), create playlist from selection; the
  resulting playlist contains exactly the selected tracks.
- Queue offers "Add queue to playlist" and "Create playlist from queue"
  (whole-queue semantics), producing a playlist with the queue's tracks
  in order.
- `cargo test --release` green; binary warnings ≤ 3 baseline.
