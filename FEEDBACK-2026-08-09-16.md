## 1. Title — change the stray "t" above the files to "▶"

**Current** (`src/ui/modals/paste.rs`, `open_torrent_file_picker`): the
title is built as

```rust
let title = format!(" Select files — {} ", scan.torrent_name);
```

With a long torrent name (e.g.
`Banana.Fish.S01.1080p.NF.WEB-DL.DUAL.AAC2.0.H.264-VARYG`) the centered
title overflows the popup and is truncated **from the left** — the user
sees a stray **"t"** (the tail of "Select") at the start of the title:

```
╭t files — Banana.Fish.S01.1080p.NF.WEB-DL.DUAL.AAC2.0.H.264-VARYG ──╮
```

**Desired** (user's drawing — the title starts with ▶):

```
╭▶ files — Banana.Fish.S01.1080p.NF.WEB-DL.DUAL.AAC2.0.H.264-VARYG ──╮
```

**Change**: the picker title becomes

```rust
let title = format!("▶ files — {} ", scan.torrent_name);
```

"Select" is dropped; "▶" is the leading marker. ("▶ files — " is 10
characters; with the observed name the title fits the title window, and
any longer name truncates to a clean "▶…" instead of a mangled letter.)

## 2. Add a 1-character margin on the right side

**Current** (`src/ui/modals/torrent_file_picker.rs`, `render`): the
file-list rows run flush to the scrollbar column — the (truncated) file
name touches the scrollbar thumb:

```
│  Banana…VARYG.S01E01.mkv↑│
```

**Desired**: one blank column between the list content and the scrollbar:

```
│  Banana…VARYG.S01E01.mkv ↑│
```

**Change**: reserve one extra column on the right of the List area —
shrink `options_area` (e.g. the list block's right padding) by 1,
keeping `scrollbar_area` where it is. The rendered rows, the click
targets (`get_at_rendered_row` / `options_area.contains`) and the
scrollbar hit column must stay consistent with the narrower area.
