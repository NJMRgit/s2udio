# Session log — 2026-08-11

## Phase 4b — QueuePane decomposition (devcontainer, 2026-08-11)

Executed the Phase 4b handoff plan
(`docs/design/Rewrite/phase4b-queue-decomposition.md`) on branch
`rewrite` (working tree was clean at `1867964`): split `src/ui/panes/
queue.rs` — the largest file in the tree (4447 LOC = 2673 production +
1775 test) — into a module root + three focused submodules, **zero
behavior change, zero test edits**. Four commits, each independently
green (`cargo test --release` **1328/1328**, warnings 3 baseline,
similarity guardrail 60 excl-thin unchanged after each):

1. **4b1** (`5bf5a18`): context menus → `queue/context_menus.rs` (347
   LOC) — `open_context_menu`, `open_audio_context_menu`,
   `open_video_context_menu`. queue.rs 4447 → 4128.
2. **4b2** (`80b4844`): video set → `queue/video.rs` (373 LOC) —
   `render_video`, `handle_video_action`, `video_load_entry`,
   `video_remove_entries`, `video_move`, `video_scroll_to`, `video_page`,
   `video_jump`, `video_play_selected`, `follow_playing_video`. queue.rs
   → 3782.
3. **4b3** (`c81cb2f`): chapters set → `queue/chapters.rs` (325 LOC) —
   `render_chapters`, `handle_chapters_action`, `chapters_move`,
   `chapters_page`, `chapters_jump`, `chapters_select_current`,
   `chapters_play_selected`, `chapters_scroll_to`, `seek_to`. queue.rs →
   3485.
4. **4b4** (close-out): re-ran the full gate; recorded ref-to-ref metrics
   (`--ref 1867964` vs `--ref HEAD`); updated
   `docs/design/Rewrite/ui-reuse-rewrite.md` (§2.4 table, phase-4 row,
   new §5.3 close-out), `HANDOFF.md` (phase 4b ✅, next = 4c/5), flipped
   the plan doc's status to done, and added this session entry.

**Design notes / gotchas hit:**

- **Submodule visibility**: private inherent methods defined in a child
  module are *not* visible from the parent module, so method resolution
  at queue.rs call sites silently fell back to the `SongListCore` trait's
  `open_context_menu` default (`Result<()>`) and broke the
  `handle_video_action` match-arm types. Fix: the moved functions are
  declared `pub(super)` (identical effective visibility to their
  original private-in-`queue` declarations, which already covered
  `queue` + its test mods). Same pattern as `search/inputs.rs`'s
  `pub(super)` items.
- **Metrics trap confirmed**: `ui-metrics.py` reads the file list from
  `git ls-tree HEAD` but contents from the worktree without `--ref`, so
  the new submodule files are silently excluded from pre-commit runs —
  all 4b numbers were measured on committed refs.
- **Stays put by design**: `current_chapters`/`chapters_available`
  (used by dispatchers/toggle too), all struct fields, the `SongListCore`
  impl, and all five `#[cfg(test)]` mods (1775 test LOC byte-identical).

**Numbers** (committed refs, `python3 scripts/dev/ui-metrics.py --ref`):
queue.rs **4447 → 3485** (production 2673 → 1711, **−962**; tests 1775 →
1775); new submodules 347 + 373 + 325; src/ui 56,987 → 57,070 (+83);
tree 96,045 → 96,128 (+83) — a pure-move split is LOC-neutral by design
(the headers/imports cost ~28 lines/file); the −950 production-LOC
target is met. Similarity guardrail: **60 excl-thin pairs, identical
pair set** before/after (moved fns keep unique names → no new pairs).

**Remaining**: the phase-4 host live-check (plan §8 — Audio/Video/
Chapters behavior, marks, context menus, toggle row, scrollbars) before
phase 4 closes; then 4c/5.

## Phase 5 — shared drawing widgets (devcontainer, 2026-08-11)

Executed the Phase 5 handoff plan
(`docs/design/Rewrite/phase5-drawing-widgets.md`) on branch `rewrite`
(working tree was clean at `64be282`): extracted the shared drawing
machinery from `ControlsPane`/`LyricsPane` into `src/ui/widgets/` —
**behavior parity, zero assertion edits** (the 2 marquee timing tests +
the wrap test moved *with* their code; assertions byte-identical).
Five commits, each independently green (`cargo test --release`
**1328/1328**, warnings 3 baseline, similarity guardrail 60 excl-thin
identical pair set after every commit):

1. **5b1** (`483a73c`): `marquee.rs` (282 LOC) — `draw_marquee` /
   `marquee_offset` / `draw_panel_at` + the `CAROUSEL_*` constants moved
   from controls.rs (cycle math untouched; the constants moved with the
   code and are now `pub(crate)` in the widget). **Cross-pane flips**:
   lyrics (601/609) **and** jellyfin (1474/1482, same coupling the plan
   greps for but a call site the plan text did not enumerate) now call
   `crate::ui::widgets::marquee::*` instead of `ControlsPane::*`;
   controls' 2 render sites use the widget's `draw_marquee`. The widget
   carries its own minimal `draw_line`/`draw_spans` (left-aligned /
   skip+clip forms of the controls helpers, which stay in controls.rs
   per the plan).
2. **5b2** (`490c62e`): `wrap.rs` (84 LOC) — `wrap_to_width` (pub(crate))
   + `wrap_spans` (pub(crate), its lyrics caller needed it) + the wrap
   test; jellyfin's `crate::ui::panes::lyrics::wrap_to_width` import
   flipped to the widget (its `scrub_emoji` import stays).
3. **5b3** (`2fcb10c`): **documented decision NOT to merge** the button
   cluster — lyrics header (`LyricsBtn`/`button_line`), controls mpv
   row-0 (`mpv_button_layout`) and the transport row (`transport_zones`)
   are three different shapes (separator style, collapse tiers,
   label-text-only vs whole-label hover, pressed glyph, zone shape,
   write primitive all differ; see plan §3a).
4. **5b4** (`ef4863f`): **documented decision NOT to merge** the
   now-playing line templates — controls `artist_title_line`/
   `channel_line` vs the lyrics info header differ in data resolution,
   styles and layout; the shared marquee cycle is already the 5b1 widget.
5. **5b5** (close-out): re-ran the full gate; recorded ref-to-ref
   metrics (`--ref 64be282` vs `--ref HEAD`); updated outline §2.4/
   phase-row/§5.4, HANDOFF (next = 6), flipped the plan doc to done, and
   added this session entry.

**Numbers** (committed refs): controls.rs **1516 → 1319** (prod −112,
tests −85), lyrics.rs **2543 → 2475** (prod −61, tests −7); new
`marquee.rs` 282 (193 prod + 89 test), `wrap.rs` 84 (72 prod + 12 test);
src/ui **57,070 → 57,173 (+103)**, tree 96,128 → 96,231 (+103) — a pure
move + widget header/doc cost; guardrail **60 excl-thin before and
after, identical pair set** (moved fns keep unique names and live in
`ui/widgets/`, outside the pane-pair analysis).

**Adopted call sites**: marquee → controls (2 render sites), lyrics
(video-info title), jellyfin (header title) — 3 panes; wrap → lyrics
(`wrap_to_width` ×2, `wrap_spans` ×1), jellyfin (overview) — 2 panes.

**Design notes / gotchas hit:**

- **The metrics trap bit mid-phase**: `--ref HEAD` before committing
  showed `marquee.rs: None` (the file list comes from `git ls-tree
  HEAD`); all final numbers are on committed refs.
- **Widget self-containment**: `draw_panel_at` needs skip+clip span
  drawing, so marquee.rs carries private `draw_line`/`draw_spans`
  equivalents (the plan's "don't drag" rule keeps controls.rs's copies
  in place for the pane's own rendering).
- **`ScrollingLine` kept** (plan §3 adopt-vs-keep): continuous
  `|`-separated modulo cycle ≠ hold-scroll-wrap carousel cycle; forcing
  one would change the property pane's visible scroll behavior.
- **Jellyfin was a 3rd marquee call site** not enumerated in the plan
  text (only lyrics was); it is the same cross-pane coupling, so it was
  flipped too (same cycle, no behavior change).

**Remaining**: the phase-5 host live-check (plan §8 — controls carousel
cycle/buttons, lyrics header cluster + info marquee + description wrap,
jellyfin overview wrap, property scrolling line); then Phase 6 (args
expansion).
