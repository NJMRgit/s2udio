**Design notes / gotchas hit:**

- **Submodule visibility**: private inherent methods defined in a child
  module are *not* visible from the parent module, so method resolution
  at queue.rs call sites silently fell back to the `SongListCore` trait's
  `open_context_menu` default (`Result<()>`) and broke the
  `handle_video_action` match-arm types. Fix: the moved functions are
  declared `pub(super)` (identical effective visibility to their
  original private-in-`queue` declarations, which already covered
  `queue` + its test mods). Same pattern as `search/inputs.rs`'s
  `pub(super)` items.
- **Metrics trap confirmed**: `ui-metrics.py` reads the file list from
  `git ls-tree HEAD` but contents from the worktree without `--ref`, so
  the new submodule files are silently excluded from pre-commit runs —
  all 4b numbers were measured on committed refs.
- **Stays put by design**: `current_chapters`/`chapters_available`
  (used by dispatchers/toggle too), all struct fields, the `SongListCore`
  impl, and all five `#[cfg(test)]` mods (1775 test LOC byte-identical).

**Numbers** (committed refs, `python3 scripts/dev/ui-metrics.py --ref`):
queue.rs **4447 → 3485** (production 2673 → 1711, **−962**; tests 1775 →
1775); new submodules 347 + 373 + 325; src/ui 56,987 → 57,070 (+83);
tree 96,045 → 96,128 (+83) — a pure-move split is LOC-neutral by design
(the headers/imports cost ~28 lines/file); the −950 production-LOC
target is met. Similarity guardrail: **60 excl-thin pairs, identical
pair set** before/after (moved fns keep unique names → no new pairs).
