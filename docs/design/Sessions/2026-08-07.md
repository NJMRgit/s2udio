*tested* client because the 4K-capable clients (android, android_vr, ios,
tv_simply) are silently skipped by yt-dlp when the session is
authenticated (SUPPORTS_COOKIES=false + Zen cookies). Running **anonymous

video up to **2160p** (itag 313/401), and audio as **single-file DASH**

`seek 45` → `0:45/95:36`.

- `conf/config`: `player_client=android_vr,web_safari` (android_vr first).

  `~/.config/yt-dlp/config` and runs with `--ignore-config` (the default
  config would leak cookies back in — found the hard way), exit 0 wins;
  (2) on failure, retry with the user's cookies (web_safari HLS ≤1080p,
