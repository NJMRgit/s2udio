Date: 2026-08-12 · Branch: `working` · **STATUS: IMPLEMENTED host-side

see the 2026-08-12 session-log entry (round 28b).**

## Context

Host live-check feedback on round 28 (2026-08-12): the Library/Search
toggle **captured `Tab` (NextTab) too**, and with `E` (NextTab) the MPD
tab was effectively unreachable from the keyboard — `Tab` and `E` both
flipped the mode instead of cycling tabs, so the only keyboard way out
was `Q`. The user's correction: **ONLY `Shift+Tab` should switch
Library/Search**; `Tab` / `E` / `Q` must keep cycling tabs so the MPD
tab can always be left.

## Change (host-implemented, round-28b commit)

1. **New global action `ToggleMpdMode`**, bound by default to
   `Shift+Tab` (`<S-Tab>`; also added to the user's live
   `~/.config/s2udio/config.ron` global table and to
   `assets/example_config.ron`).
2. **`DirectoriesPane::handle_action`** now claims `ToggleMpdMode`
   (and ONLY it) while the MPD tab is focused → `toggle_mode()`. The
   round-28 `NextTab` claim is gone: `Tab` / `E` (NextTab) and `Q`
   (PreviousTab) fall through to the global handler and cycle tabs as
   before — the MPD tab is always reachable/leavable from the keyboard.
3. **Everywhere else `ToggleMpdMode` is a no-op** (global executor
   arm). The queue's `Shift+Tab` = ToggleChapters is untouched: the
   queue pane claims the queue half first, so the global half never
   fires there (key resolution produces
   `Queue(ToggleChapters) + Global(ToggleMpdMode)` for one press).
4. Tests: `tab_toggles_the_library_search_mode` →
   `shift_tab_toggles_the_library_search_mode` (+ new
   `tab_and_q_do_not_toggle_the_mode`). **1361/1361**, binary warnings
   3 baseline.

## Acceptance criteria (host-validated after the pull)

- MPD tab: `Shift+Tab` flips Library ↔ Search (both directions; from
  Library and from Search mode).
- MPD tab: `Tab`, `E` and `Q` cycle tabs (leave the MPD tab) — they
  never flip the mode.
- Queue tab: `Shift+Tab` still cycles Audio → Video → Chapters.
- Other tabs: `Shift+Tab` does nothing (no tab jump).
- `cargo test --release` green; binary warnings ≤ 3 baseline.
